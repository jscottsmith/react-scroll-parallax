# Agent instructions

## Project skills

This repository keeps agent skills under `.agents/skills/<skill-name>/`.

**Before work that matches a skill’s purpose** (or when unsure whether a skill applies), read the skill’s `SKILL.md` with the Read tool:

`.agents/skills/<skill-name>/SKILL.md`

To discover what exists, list `.agents/skills/` and open each skill’s `SKILL.md` when its scope fits the task.

### Current skills

None in-repo yet. Add `.agents/skills/<skill-name>/SKILL.md` when you need project-only skills (global skills live under `~/.cursor/skills/`).
