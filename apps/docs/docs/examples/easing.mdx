# Easing Animation

Parallax easing uses CSS/WAAPI [`animation-timing-function`](https://developer.mozilla.org/en-US/docs/Web/CSS/animation-timing-function) values: timing keywords or `cubic-bezier(...)`.

## Global easing

Set `easing` on the hook/component to apply the same curve to every effect that does not define its own tuple easing:

```tsx
function Component() {
  const parallax = useParallax<HTMLDivElement>({
    easing: 'ease-out',
    translateX: [0, 100],
  });
  return <div ref={parallax.ref} />;
}
```

:::important

When `easing` is set at the top level, it applies to all effects unless a given effect overrides it with a 3rd tuple value (see below).

:::

## Per-effect easing (3rd tuple value)

Pass easing as the optional third entry on any effect tuple. Each effect can use its own curve:

```tsx
function Component() {
  const parallax = useParallax<HTMLDivElement>({
    translateY: [-100, 100, 'ease-in'],
    scale: [0, 1, 'cubic-bezier(0.2, -0.67, 1, -0.62)'],
  });
  return <div ref={parallax.ref} />;
}
```

Supported values for tuple easing (and for the top-level `easing` prop):

- Timing keywords: `linear`, `ease`, `ease-in`, `ease-out`, `ease-in-out`, `step-start`, `step-end`
- `cubic-bezier(x1, y1, x2, y2)`

Legacy preset names such as `easeInOut` or `easeOutBack` are not accepted; use the keyword or cubic-bezier equivalent (see the [V3 migration guide](/docs/migration-guides/v3-migration-guide#legacy-preset--cubic-bezier-reference-from-the-old-mapping)).

## Custom cubic-bezier

```tsx
function Component() {
  const parallax = useParallax<HTMLDivElement>({
    easing: 'cubic-bezier(1, -0.75, 0.5, 1.34)',
    translateX: [0, 100],
  });
  return <div ref={parallax.ref} />;
}
```
