# Easing Animation

You can provide CSS/WAAPI [`animation-timing-function`](https://developer.mozilla.org/en-US/docs/Web/CSS/animation-timing-function) values directly to the `easing` prop (for example `'ease-out'` or `'cubic-bezier(1, -0.75, 0.5, 1.34)'`).

## Example using a keyword

This `translateX` effect will be eased using the `ease-out` keyword.

```tsx
function Component() {
  const parallax = useParallax<HTMLDivElement>({
    easing: 'ease-out',
    translateX: [0, 100],
  });
  return <div ref={parallax.ref} />;
}
```

:::important

When defining an `easing` prop like above, ALL provided CSS effects will be eased.

:::

<EasingDemo eased={{ easing: 'ease-out' }} />

## Custom cubic-bezier

Define a custom cubic-bezier curve as a timing-function string.

```tsx
function Component() {
  const parallax = useParallax<HTMLDivElement>({
    easing: 'cubic-bezier(1, -0.75, 0.5, 1.34)',
    translateX: [0, 100],
  });
  return <div ref={parallax.ref} />;
}
```
