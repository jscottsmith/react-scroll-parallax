React hooks and components to create scroll-driven parallax effects for banners, images, or any other DOM elements. Built on [Parallax Controller](https://parallax-controller.damnthat.tv/docs/v2/intro), powered by the Web Animations API where each element is driven by a ScrollTimeline or ViewTimeline. Apply translate, rotate, scale, and opacity keyframes with scroll progress on the compositor and don't block the main thread.

## Install

:::tip 4.0 Beta

Uses the latest [Parallax Controller](https://parallax-controller.damnthat.tv/docs/v2/intro) built with **Web Animations API** for scroll-driven animations.

If you're upgrading from V3, here's a [migration guide to the v4 beta](/docs/migration-guides/upgrade-to-v4).

Note that **Firefox does not support the** [Web Animations ViewTimeline API](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-timeline/view#browser_compatibility). You will need to use a [polyfill](https://github.com/flackr/scroll-timeline).

:::

```
npm install react-scroll-parallax@beta
```

:::warning Browser Support

Note that **Firefox does not support the** [Web Animations ViewTimeline API](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-timeline/view#browser_compatibility). You will need to use a [polyfill](https://github.com/flackr/scroll-timeline). It's currently behind a flag in Firefox and enabled by default in Firefox Nightly if you want to try it out.

:::

## Example

[Create effects](/docs/v4/examples/how-it-works) with a hook:

```jsx
function Component() {
  const parallax = useParallax({
    speed: -10,
  });
  return <div ref={parallax.ref} />;
}
```

or with a component:

```jsx
function Component() {
  return (
    <Parallax speed={-10}>
      <div />
    </Parallax>
  );
}
```
